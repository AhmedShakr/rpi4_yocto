Poky & Build Directory Structure Reference (Lecture 11 - RPi4 64-bit)
#####################################################################
- Console Latest Log : poky/build/tmp/log/cooker/raspberrypi4-64/console-latest.log
- Final Images Dir   : poky/build/tmp/deploy/images/raspberrypi4-64/
- Final Packages Dir : poky/build/tmp/deploy/rpm/ (or ipk/deb)
- Final SDK Dir      : poky/build/tmp/deploy/sdk/
- Target Arch WorkDir: poky/build/tmp/work/cortexa72-poky-linux/<package>/<version>/
- Machine WorkDir    : poky/build/tmp/work/raspberrypi4_64-poky-linux/
- Host Native WorkDir: poky/build/tmp/work/x86_64-linux/
- Recipe Task Logs   : <WORKDIR>/temp/log.task_order, log.do_<task>, run.do_<task>

Cloning Additional Layers (Lecture 12)
######################################
- OpenEmbedded Layer Index (scarthgap):
  https://layers.openembedded.org/layerindex/branch/scarthgap/layers/

- General Command to Clone a Layer:
  $ cd poky
  $ git clone <layer_git_url> -b scarthgap

- Cloned Layers for Our RPi4-64 Project:
  $ cd poky
  $ git clone https://github.com/openembedded/meta-openembedded.git -b scarthgap
  $ git clone https://github.com/meta-qt5/meta-qt5.git -b scarthgap
  $ git clone https://git.yoctoproject.org/meta-raspberrypi -b scarthgap

Custom Layer Creation & Configuration (Lecture 13 - meta-moz)
#############################################################
- Custom Layer Path      : poky/meta-moz
- Layer Config File      : poky/meta-moz/conf/layer.conf
- Layer Collection Name  : BBFILE_COLLECTIONS += "moz"
- Layer Priority         : BBFILE_PRIORITY_moz = "20" (Highest priority)
- Layer Compatibility    : LAYERSERIES_COMPAT_moz = "nanbield scarthgap"
- Layer Dependencies     : LAYERDEPENDS_moz = "core raspberrypi"
- Verify Active Layers   : $ bitbake-layers show-layers
